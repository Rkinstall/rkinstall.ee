KUIDAS SAADA LEHT PÄRISELT INTERNETTI
1) GitHub Pages (tasuta):
   - loo GitHubis repository
   - lae selle ZIPi sisu repository juurkausta
   - Settings > Pages > Deploy from a branch > main / root
   - lisa Pages seadetes custom domain: www.rkinstall.ee
   - muuda domeeni DNS-is www CNAME GitHub Pagesi antud aadressile

2) Netlify (tasuta):
   - logi Netlifysse sisse
   - lohista see veebikaust Netlify Dropi
   - Domain management alt lisa www.rkinstall.ee
   - järgi Netlify antud DNS-juhiseid

NB! Domeeni www.rkinstall.ee avalikuks sidumiseks on vaja ligipääsu selle domeeni DNS-seadetele.
Ära jaga paroole vestluses; logi teenusesse ise sisse või kasuta ühendatud integratsiooni.
